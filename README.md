# grove-anthropic

Tools for using Anthropic/Claude API plaform

## Installation

```bash
grove install grove-anthropic
```

## Usage

```bash
grove-anthropic --help
```

## Development

### Building

```bash
make build
```

### Testing

```bash
make test
make test-e2e
```

### Linting

```bash
make lint
```
